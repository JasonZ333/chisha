# 【吃啥】50 道菜 AI 绘图提示词

配套软件：吃啥（第一版）
用途：给内置的 50 道示例菜品生成图片，放进软件的「图片文件夹」后自动替换统一占位图。

---

## 一、怎么用（三步）

1. **打开图片文件夹**
   运行「吃啥」→ 右上角齿轮「设置」→「数据保存位置」→ 点「打开图片文件夹」。

   > 请以这里显示的路径为准。默认位置是：
   >
   > ```
   > C:\Users\<你的用户名>\AppData\Roaming\chisha\images
   > ```
   >
   > 如果 `%APPDATA%` 被系统权限策略限制，程序会自动改用其他可写目录
   > （比如 exe 同级的 `chisha-data\images`），设置页里会显示实际路径。

2. **生成图片**
   把下面 50 条提示词逐条丢进任意 AI 绘图工具（豆包、即梦、通义万相、Midjourney、Stable Diffusion 等）。
   建议统一出图规格：**16:10 横图，1280 × 800 以上，PNG 或 JPG**。

3. **按文件名保存**
   按下面每条的**文件名**保存/重命名，放进图片文件夹。
   重启「吃啥」，图片自动生效；没有放图的菜继续显示统一占位图，不影响使用。

> 只要文件名对得上就行，扩展名 `.png` / `.jpg` / `.jpeg` / `.webp` 都认。

---

## 二、通用前缀（建议每条都带上）

```
美食摄影，俯拍 45 度特写，暖色调，自然光，浅景深背景虚化，木质餐桌，
画面干净，食物诱人、有热气或油光质感，无文字，无水印，无人物，无logo，
图片比例 16:10，超高清。
```

> 如果你的工具只能贴一段，就把「通用前缀 + 该条专属描述」拼成一段再提交。
