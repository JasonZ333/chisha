# 吃啥 · 微信小程序版

这是「吃啥」的**微信小程序版**，与 `D:\chisha` 下的 Flutter 桌面版是**两套独立代码**。

> Flutter **不能**编译成微信小程序（小程序用 WXML/WXSS/JS），所以这里是原生小程序项目。

## 怎么打开（已实测）

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 目录选 `D:\chisha\miniprogram`
3. AppID 填项目自己的正式号 `wx7e9f83d00671529f`（`project.config.json` 里已写好，导入时会自动带出）；**不要填 `touristappid`**
4. 弹出「您信任此项目的作者吗？」→ 点**「信任并运行」**

> ⚠️ **`project.config.json` 里不要写 `"appid": "touristappid"`。**
> 本版工具（Stable 2.01.2510290）会报 `更改 AppID 失败 touristappid / Error: tourist appid`，
> 模拟器起不来。**去掉 appid 字段**后工具会自动回落到**游客模式**，界面可以正常跑。
> 正式上传前再填你自己的真实 AppID。

## 附近美食随机（IP 定位，**不需要微信位置权限**）

点「附近美食随机」→ 按**网络 IP** 判断城市/区 → 腾讯位置服务周边搜索（5 公里）→
从结果里随机挑一家 → 弹窗显示店名/距离/地址，可点「导航过去」。
结果弹窗顶部会显示「当前定位：北京市 昌平区」，并提供**「改地点」**入口
（输入商圈/地铁站，用腾讯位置服务的关键词提示转成坐标）。

### 为什么用 IP 定位，而不是 `wx.getLocation`

`wx.getLocation` 属于微信「地理位置接口」，2022 年起**按服务类目准入**：

- 只对「与实时地理位置强相关」的类目开放（同城配送、打车、到店自提等）
- 这些类目基本都要求**企业资质**；个人主体申请会被提示「类目未符合开通条件」

而腾讯位置服务的 IP 定位只是普通 WebServiceAPI 请求，**不需要任何微信权限**，
个人主体立即能用。代价是**精度只到区级**，所以搜索半径放大到 5 公里，
并提供了「改地点」让用户自己精确指定。

### 需要配置的两件事

| # | 要做的 | 在哪里 |
| --- | --- | --- |
| 1 | 申请免费 key（需实名认证，否则每日额度极小） | [lbs.qq.com](https://lbs.qq.com/) → 控制台 → 应用管理 → 创建应用 → 添加 key（**勾选 WebServiceAPI**） |
| 2 | 把 `https://apis.map.qq.com` 加进 **request 合法域名** | 微信公众平台 → 开发 → 开发管理 → 服务器域名 |

key 填在 `utils/nearby_key.js`（**该文件不入库**，见 `.gitignore`）：

```js
module.exports = '你的 key';
```

> 用了 IP 定位后，`app.json` 里**不再**声明 `requiredPrivateInfos` / `scope.userLocation`
> —— 因为我们不碰设备位置，也就不需要位置隐私接口和类目审批。

**已实测**：直接用 key 调 IP 定位接口返回
`{city: 北京市, district: 昌平区, lat: 40.22, lng: 116.23}`，
周边搜索也能返回 20 家真实店铺（如「故宫快餐 231 米」）。

> ⚠️ 免费额度很小：实测调几次就会返回 `121 此key每日调用量已达到上限`。
> 这个接口每天 0 点重置；想稳定使用请先去腾讯控制台实名/提额。

**怎么查任意小程序的 AppID**：微信里打开该小程序 → 右上角「…」→ 点小程序名称进详情页
→ 点「更多资料」→ 里面就有 AppID。

**降级机制**：如果某个平台的 `appId` 被清空，点击它不会报错，只会提示
「已复制菜名，请到 App 里粘贴搜索」。这条兜底路径有独立测试守着。

**为什么能跳**：`wx.navigateToMiniProgram` **不同主体的小程序可以互相跳转，不需要关联**，
且自 2020-04-24 起无需在 `app.json` 里声明跳转名单、不受数量限制。
限制是必须**用户点击触发**，且跳转前微信会弹系统确认框。

⚠️ 还要遵守[《微信小程序平台运营规范》](https://developers.weixin.qq.com/miniprogram/product/)关于**「互推行为」**的要求，
所以这里的文案写成"帮你去点这道菜的外卖"，而不是平台之间的互推。

> **注意**：只能跳到目标小程序的**首页**。美团/饿了么/京东没有公开"搜索关键词"的页面路径，
> 所以实际流程是：**菜名先复制到剪贴板 → 跳过去 → 在 App 里粘贴搜索**（这正是界面里那句提示的意思）。

## 已知约束

- **图片必须打包**：小程序的网络请求域名必须是自己**备案并校验过**的域名，
  所以不能在线加载 Wikimedia 的图片。桌面版那份 6.9 MB 压缩到 23 KB/张后随包发布。
- **主包上限 2 MB**：当前图片合计 1.11 MB，加上代码仍在限制内。以后加图需注意。
- **个人主体小程序**功能受限（不能开微信支付、部分类目不可选），但本项目的功能不受影响。
